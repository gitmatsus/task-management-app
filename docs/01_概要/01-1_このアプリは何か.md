# 01-1 このアプリは何か

`TList.html` という **単一HTMLファイル** で完結するブラウザ向けタスク管理アプリです。バニラJSとlocalStorageのみで動き、サーバーや外部ライブラリを必要としません。同じ `TList.html` を Electron / Tauri / Photino で包んでネイティブアプリとしても起動できます。

## 機能一覧

| カテゴリ | 機能 | 概要 |
|---|---|---|
| タスク | CRUD | 追加・編集・完了チェック・削除（ゴミ箱経由） |
| タスク | 期限日 | `YYYY-MM-DD` 形式、期限切れ／今日／未来でバッジ色分け |
| タスク | 開始日 | `YYYY-MM-DD` 形式、未来日は表示抑制（今日以降で表示） |
| タスク | サブタスク | メイン → サブの2階層、ドラッグでメイン⇔サブ変換、折りたたみ可 |
| タスク | 完了日時 | チェックON時に `completedAt` を自動記録、テキスト下に「✓ MM/DD HH:mm 完了」表示 |
| タスク | 詳細メモ | 複数行テキスト、メモボタンでポップアップ表示 |
| タスク | フォルダ／URL | パスまたはURLを紐付け、ボタンで開く |
| タスク | 多行入力 | Shift+Enterで改行、Enterで追加・保存 |
| リスト | 複数リスト | サイドバーで切替、名前変更、ドラッグ並び替え |
| リスト | リストタイプ | 通常リスト（todo）／メモリスト（memo）の2種 |
| リスト | リストゴミ箱 | リスト削除時に退避、復元・完全削除可 |
| リスト | リスト折りたたみ | 5件超は折りたたみ、選択中は常に表示 |
| リスト | ステータスドット | 期限切れ／今日／未来／期限なし／完了をカラーで表示 |
| 表示 | フィルター | すべて／未完了／完了 |
| 表示 | ダークモード | トグル、`localStorage` 永続化（既定オン） |
| 表示 | 先頭追加トグル | 新規タスクをリスト先頭／末尾どちらに入れるか |
| 表示 | 自動整列 | 期限日順に常時ソート |
| 操作 | ドラッグ＆ドロップ | デスクトップ：タスク・リストの並び替え、リスト間移動、ゴミ箱投入 |
| 操作 | タッチ並び替え | グリップ長押しで並び替え |
| 操作 | リスト間移動（モバイル） | タスク長押し → ポップアップでリスト選択 |
| データ | インポート／エクスポート | JSON、リスト単位で選択可、ファイルD&Dでも取込 |
| データ | ゴミ箱 | タスクゴミ箱／リストゴミ箱（それぞれ復元・完全削除） |
| 環境 | PWA | Canvas生成アイコン、`apple-touch-icon`、manifest |
| 環境 | セーフエリア | `env(safe-area-inset-*)` でiOS Dynamic Island対応 |

## できないこと（適用範囲外）

- **クラウド同期**: 端末／環境間でデータは共有されません。移行はJSONエクスポート／インポートで行います。
- **共同編集・共有**: ユーザー認証や共有機能はありません。
- **通知・リマインダ**: OS通知やプッシュ通知は実装されていません。
- **添付ファイル**: バイナリ添付は不可（フォルダパス／URLの記録のみ）。
- **Outlook連携**: 検討されたが、`outlook:` プロトコルがWindows未登録のため断念（[HANDOFF.md](../../HANDOFF.md) 「未実装・検討事項」）。

## 主な利用シーン

1. 個人のToDo管理（業務／プライベートをリストで分ける）
2. プロジェクトごとのタスク + 関連フォルダ／URLを1か所に集約
3. メモリストとして、期限を持たない情報の蓄積
4. 端末ローカルで完結する軽量タスク管理（社内ネットワーク／オフライン）
5. ネイティブ化（Electron／Tauri／Photino）してインストール型アプリとして配布
