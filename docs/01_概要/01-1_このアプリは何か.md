# 01-1 このアプリは何か

`TList.html` という **単一HTMLファイル** で完結するブラウザ向けタスク管理アプリです。バニラJSとlocalStorageのみで動き、サーバーや外部ライブラリを必要としません。同じ `TList.html` を **Tauri (v2)** で包んでネイティブアプリとしても起動できます（軽量・小サイズ）。

## 機能一覧

| カテゴリ | 機能 | 概要 |
|---|---|---|
| タスク | CRUD | 追加・編集・完了チェック・削除（ゴミ箱経由） |
| タスク | 期限日 | `YYYY-MM-DD` 形式。超過=赤／今日=黄／今週中=緑／来週以降=水でバッジ色分け |
| タスク | 開始日 | `YYYY-MM-DD` 形式。常時表示（今日=黄／未来=水／過去=灰） |
| タスク | 同日統合バッジ | 開始日=終了日のとき「▶📅 今日」のように両アイコン併記 |
| タスク | 繰り返し | 毎日／毎週X曜／毎月X日 or 末日。完了後に周期境界を超えたら自動で未完了化＋次回 `dueDate` へ進める |
| タスク | サブタスク | メイン → サブの2階層、ドラッグでメイン⇔サブ変換、折りたたみ可。メモリストでも完全サポート |
| タスク | サブ完了トグル | 親内に完了サブが残れば「▷ 完了 (N件)」で折り畳み展開 |
| タスク | 完了日時 | チェックON時に `completedAt` を自動記録、テキスト下に「✓ MM/DD HH:mm 完了」表示 |
| タスク | 詳細メモ | 複数行テキスト、メモボタンでポップアップ表示 |
| タスク | フォルダ／URL | パスまたはURLを紐付け、ボタンで開く |
| タスク | 多行入力 | Shift+Enterで改行、Enterで追加・保存 |
| リスト | 複数リスト | サイドバーで切替、名前変更、ドラッグ並び替え |
| リスト | リストタイプ | 通常リスト（todo）／メモリスト（memo）の2種 |
| リスト | リストゴミ箱 | リスト削除時に退避、復元・完全削除可。削除は右クリック/長押しメニューから（誤操作防止） |
| リスト | リスト折りたたみ | 5件超は折りたたみ、選択中は常に表示 |
| リスト | ステータスドット | 期限切れ／今日／未来／期限なし／完了をカラーで表示 |
| リスト | 緊急度カラー | サイドバー件数バッジを 5 段階で色分け（超過/今日/今週中/来週以降/既定） |
| 表示 | フィルターチップ | すべて／今週中／着手可能／超過／今日 の 5 種類 |
| 表示 | 完了セクション | 完了済みタスクを下部「▶ 完了 (N件)」に折り畳んで集約 |
| 表示 | 全て折り畳み/展開 | リストヘッダーの▶/▽トグルボタン |
| 表示 | ダークモード | トグル、`localStorage` 永続化（既定オン） |
| 操作 | 右クリック/長押しメニュー | タスク: 編集/削除/サブに登録▶/メインに昇格。リスト: 名前変更/削除 |
| 操作 | ドラッグ＆ドロップ | デスクトップ：タスク・リストの並び替え、リスト間移動、ゴミ箱投入、サブ化（下60%）／メイン化（上40%） |
| 操作 | タッチ並び替え | グリップ長押しで並び替え |
| 操作 | リスト間移動（モバイル） | タスク長押し → ポップアップでリスト選択（サブなら「⬆️ メインに昇格」も） |
| 操作 | ＋ボタン | 各メイン右側、押すと「`<親名>` のサブタスクを入力...」モードで連続追加 |
| データ | インポート／エクスポート | JSON、リスト単位で選択可、ファイルD&Dでも取込 |
| データ | ゴミ箱 | タスクゴミ箱（親子関係維持表示）／リストゴミ箱 |
| 環境 | PWA | Canvas生成アイコン、`apple-touch-icon`、manifest |
| 環境 | セーフエリア | `env(safe-area-inset-*)` でiOS Dynamic Island対応 |

## できないこと（適用範囲外）

- **クラウド同期**: 端末／環境間でデータは共有されません。移行はJSONエクスポート／インポートで行います。
- **共同編集・共有**: ユーザー認証や共有機能はありません。
- **通知・リマインダ**: OS通知やプッシュ通知は実装されていません。
- **添付ファイル**: バイナリ添付は不可（フォルダパス／URLの記録のみ）。
- **Outlook連携**: 検討されたが、`outlook:` プロトコルがWindows未登録のため断念（[HANDOFF.md](../../HANDOFF.md) 「未実装・検討事項」）。

## 主な利用シーン

1. 個人のToDo管理（業務／プライベートをリストで分ける）
2. プロジェクトごとのタスク + 関連フォルダ／URLを1か所に集約
3. メモリストとして、期限を持たない情報の蓄積
4. 端末ローカルで完結する軽量タスク管理（社内ネットワーク／オフライン）
5. Tauri でネイティブ化してインストール型アプリとして配布（~10MB の NSIS インストーラ）
