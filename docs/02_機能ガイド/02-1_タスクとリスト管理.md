# 02-1 タスクとリスト管理

## データモデル

### タスク（`todos` 配列）

```javascript
{
  id: string,           // crypto.randomUUID()
  text: string,         // 本文（改行可）
  completed: boolean,
  createdAt: number,    // Date.now()
  listId: string,       // 所属リストID
  dueDate?: string,     // 'YYYY-MM-DD' 終了日
  startDate?: string,   // 'YYYY-MM-DD' 開始日（メイン・サブ両方で使用）
  folderPath?: string,  // フォルダパス or URL
  linkType?: string,    // 'folder' | 'url'
  detail?: string,      // 詳細・メモ（複数行可）
  parentId?: string,    // ◀ 値があればサブタスク。親はメインのみ（2階層固定）
  completedAt?: number, // チェックON時に Date.now() を自動セット／OFFで undefined
  recurrence?: {        // 繰り返し設定（あれば繰り返しタスク）
    type: 'daily' | 'weekly' | 'monthly',
    weekday?: 0-6,      // type:'weekly' のとき、0=日〜6=土
    day?: 1-31 | 'last', // type:'monthly' のとき、'last' は月末
  },
  // 内部用（エクスポートからは除外）
  _trashedWithParent?: string, // 親と一緒にゴミ箱化されたサブの目印
}
```

> 繰り返し設定の詳細は [HANDOFF.md](../../HANDOFF.md) §「繰り返しタスク仕様」を参照。

### メイン／サブの2階層構造

- `parentId` が未設定 → メインタスク
- `parentId` がメインタスクのIDを指す → そのメインのサブタスク
- **サブのサブは作成不可**（2階層固定）
- ヘルパー: `subTodosOf(parentId)` / `hasSubs(id)` / `isSubTask(t)` / `getParent(t)`

### 完了・削除の親子振る舞い

| 操作 | 親子の動き |
|---|---|
| 完了チェック | **独立**（メイン⇔サブで連動しない） |
| 完了時刻記録 | チェックON時に `completedAt = Date.now()`、OFFで `undefined` |
| 親完了時のグループ扱い | 親完了 **かつ未完了サブが残っていない** → グループ全体を completed に振り分け。**未完了サブが残っていれば active 側に留める**（`a3eab13`） |
| メイン削除（ゴミ箱化） | サブも一緒に追従。サブ側に `_trashedWithParent = 親ID` の印を付けて `trash` へ |
| ゴミ箱から復元 | メイン復元時、`_trashedWithParent` または `parentId` が一致するサブをまとめて復元（`8ea0f65`） |
| 完全削除 | メインの完全削除時、ペアになったサブも `trash` から除去 |
| ゴミ箱内表示 | メインの下にサブをインデントしてグルーピング表示（`b9355f8`） |
| サブ単体復元 | 元の親が `todos` に存在しなければメイン化して復元（`b9355f8`） |
| リスト間移動 | メイン移動時、サブもまとめて新リストへ。サブ単体を別リストへ移動した場合は `parentId` をクリアしてメイン化（孤児化を防ぐため） |
| メモリストへの移動 | メイン・サブ問わず `completed` を自動解除 |

### サブグループ内の完了トグル（`c65408c`）

親メインが未完了で、その配下に **完了サブが残っている** ときは、未完了サブの後ろに「▷ 完了 (N件)」トグルが描画されます（`data-a="toggle-done-subs"`）。展開状態は `expandedDoneSubs: Set<string>`（親IDセッション保持、非永続）で管理。

### 折りたたみ

サブを持つメインの先頭にトグル（`▶`／`▽`）が出ます。状態は **セッション単位** で `collapsedIds: Set<string>` に保持（localStorage には保存しない）。`data-a="toggle-collapse"` で開閉。

「全て折り畳む / 全て展開する」ボタンがリストヘッダーにあり、現在リスト全メインの折りたたみを一括切替できます（`21ce223`、アイコンは `chevronRight` を `.expanded` クラスで回転、`3dff973`）。

### ＋ボタン（サブタスク連続追加）

各メイン行右側に「＋」ボタンがあり、押すと入力欄が「`<親名>` のサブタスクを入力...」モードに切り替わります（`subInputParentId`）。Enter を押すたびに同じ親へサブが追加され続けます。タッチ環境では常時表示、デスクトップは hover で表示（`9e54034`）。

### サブの昇格

- デスクトップ: サブをドラッグして別メインの行の上半分にドロップするとメイン化
- 右クリックメニュー: 「⬆️ メインに昇格」（`data-a="promote-to-main"`、サブのときのみ表示）
- モバイル: タスクの長押し → リスト移動ポップアップ内に「⬆️ メインに昇格」が追加表示

詳細なドラッグ仕様は [02-3 ドラッグドロップ操作](02-3_ドラッグドロップ操作.md) を参照。

### 右クリック / 長押しメニュー（`33e13a6`, `bb6cc74`）

タスク右クリック（デスクトップ）と長押し（モバイル）で開きます。

| 項目 | 動作 |
|---|---|
| ✏️ 編集 | 編集モード開始 |
| ✏️ サブに登録 ▶ | hover/タップで候補メイン一覧を展開、選択で `parentId` を設定 |
| ⬆️ メインに昇格 | サブの場合のみ表示。`parentId` をクリア |
| 🗑️ 削除 | ゴミ箱へ移動 |

候補メイン = 同リスト内の他のメイン（自身・現在の親・完了済みを除外）。自身がサブを持つメインの場合は「サブに登録」は非表示（2階層制限）。モバイルではタップでサブメニュー展開（`ctxSubmenuOpen` フラグ）。

リスト名の右クリック / 長押しメニュー:

| 項目 | 動作 |
|---|---|
| ✏️ 名前を変更 | rename モード |
| 🗑️ リストを削除 | リストゴミ箱へ移動。最後の1リストは非表示 |

> 未完了タスクのゴミ箱ボタン（行内 🗑️）は廃止され、右クリック/長押しメニューに移行しました（誤操作防止）。**完了済みタスクとメモタスクには現在もゴミ箱ボタンが表示** されます（`ea69a74`）。リストのゴミ箱ボタンも廃止され、メニューに移行（`bb6cc74`）。

### リスト（`lists` 配列）

```javascript
{
  id: string,           // crypto.randomUUID()
  name: string,
  createdAt: number,
  type?: string,        // 'memo' のときメモリスト、未指定は通常リスト(todo)
}
```

## タスクCRUD

| 操作 | 操作方法 | 関数 | 結果 |
|---|---|---|---|
| 追加 | 入力欄 + Enter or 「追加」ボタン | `addTodo(form)` | 常にリスト先頭に追加（`3dff973` で先頭追加トグルを廃止しデフォルト化） |
| サブ連続追加 | メイン行の「＋」 → Enter | `subInputParentId` モード | 同じ親のサブを連続追加 |
| 改行 | Shift+Enter | - | 入力欄内で改行 |
| 編集開始 | タスク本文をダブルクリック or 右クリック→編集 | `startEdit(id)` | 本文・期限・開始日・繰り返し・リンク・メモを編集 |
| 編集確定 | Enter または「保存」 | `commitEdit()` | 更新→`save()`→`render()` |
| 完了切替 | 左端のチェックボックス | `toggleTodo(id)` | `completed` を反転（ON時に `completedAt` 付与） |
| 削除 | 右クリック/長押し → 削除 / 完了済み/メモはゴミ箱ボタン / D&Dでゴミ箱ボタンへ | `moveToTrash(id)` | `trash` 配列へ移動 |

> `addToTop` / `autoSort` トグルは廃止されました（`3dff973`）。新規タスクは常に先頭追加、整列は手動 D&D のみ。完了済みは完了セクション・繰り返しは自動進行で並びが整います。

## 複数リスト管理

- サイドバーに `lists` を全件表示。`selectedListId` で現在のリストを切替。
- 5件超は折りたたみ（`LIST_COLLAPSE_LIMIT = 5`）。**選択中のリストは常に表示**。
- リスト名のダブルクリックで名前変更。
- 「＋リストを追加」で新規作成。
- リスト削除時は `listTrash` に退避（タスクごと退避）。リスト復元で同時に元のタスクも復元。

### リストタイプ（todo / memo）

`list.type === 'memo'` の場合、UI が変化します。

| 要素 | 通常リスト | メモリスト |
|---|---|---|
| 入力プレースホルダ | 「新しいタスクを入力...」 | 「新しいメモを入力...」 |
| アイコン | クリップ (`I.clip`) | ノート (`I.notepad`) |
| フィルターチップ | 表示（5種類） | 非表示 |
| 完了セクション | 表示 | 非表示（チェック概念なし） |
| 件数表示 | `残り N 件` | `N 件` |
| 件数バッジ | 未完了件数（`s.active`）、緊急度カラー | 全件（`s.total`）、既定色 |
| サブタスク | 完全サポート | 完全サポート（`9e54034` / `292f859`） |
| ゴミ箱ボタン | 完了済みのみ表示 | 常時表示（`ea69a74`） |

メモリストへタスクを移動した場合、移動時に `completed` チェックは自動解除されます（コミット `bbdc065`）。サブをメモリストへ移動した場合は `parentId` を保持したまま運ぶ（`9e54034` 以降、メモリストでもサブを表示可能）。

## ステータスドット / 緊急度カラー

`listStats(lid)` がリストごとに以下のカテゴリ別件数を返します。

| カテゴリ | 条件 |
|---|---|
| `total` | 全件 |
| `active` | 未完了 |
| `done` | 完了 |
| `overdue` | 未完了 ∧ `dueDate < today()` |
| `dueToday` | 未完了 ∧ `dueDate === today()` |
| `dueWeek` | 未完了 ∧ `today() < dueDate <= endOfWeekYmd()` |
| `weekPlus` | 未完了 ∧ `dueDate > endOfWeekYmd()` |
| `noDate` | 未完了 ∧ `dueDate` 未設定 |

サイドバー右の「ステータス表示」トグル（`toggleListStats`）でドット表示の ON/OFF を切替可能（`todo-app-show-stats`）。

### サイドバー件数バッジの緊急度カラー（`e4fbcc2`, `d1448e0`）

リスト件数バッジは **未完了件数（`s.active`）** を表示し、最も緊急度の高い区分に応じて色分けされます（5段階、メモリストは既定色）。

| クラス | 条件 | 色 |
|---|---|---|
| `urgent-ov` | `s.overdue > 0` | 赤 |
| `urgent-td` | `s.dueToday > 0` | 橙 |
| `urgent-fu` | `s.dueWeek > 0` | 緑 |
| `urgent-far` | `s.weekPlus > 0` | 水 |
| （無印） | それ以外 | 既定 |

> ステータスドットの集計は **サブも含む全タスク** が対象です（`listStats()` は `parentId` を区別しません）。

## ゴミ箱

| 種類 | 配列 | 永続化キー |
|---|---|---|
| タスクゴミ箱 | `trash` | `todo-app-trash` |
| リストゴミ箱 | `listTrash` | `todo-app-list-trash` |

復元・完全削除はそれぞれのゴミ箱画面から行います。ゴミ箱内ではメインの下にサブをインデントしてグルーピング表示し、親復元時に削除済みサブも一緒に復元されます（`b9355f8`, `8ea0f65`）。

> 以前は「ゴミ箱→フィルターボタンへのドラッグで状態指定して復元」できましたが、フィルターチップ刷新（`2b506ff`）に伴い廃止され、現在は復元ボタンのみです。
