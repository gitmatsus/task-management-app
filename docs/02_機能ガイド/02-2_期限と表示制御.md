# 02-2 期限と表示制御

## 期限日の保存形式

タスクの `dueDate`（終了日）と `startDate`（開始日）はいずれも `'YYYY-MM-DD'` 文字列で保存されます。日付の比較・生成は **ローカル時刻ベース** で行います。

```javascript
const ymd = (d) => `${d.getFullYear()}-${String(d.getMonth()+1).padStart(2,'0')}-${String(d.getDate()).padStart(2,'0')}`;
const today        = () => ymd(new Date());
const tomorrow     = () => ymd(new Date(Date.now() + 86400000));
const endOfWeekYmd = () => ymd(new Date(Date.now() + 6 * 86400000));
```

> 以前は `toISOString().slice(0,10)` でUTC基準だったため、JST深夜0時〜9時に期限切れ判定がずれるバグがありました（コミット `9ab45b4` で修正）。詳細は [05-2 既知の制約とハマりどころ](../05_リファレンス/05-2_既知の制約とハマりどころ.md)。

## バッジ表示（`b034381`）

タスク行右側にバッジが表示されます。期限（終了日）・開始日・繰り返しの3系統。色は全体で統一されています。

### 終了バッジ（`dueBadge`）

| 状態 | 条件 | 表示 / 色 |
|---|---|---|
| 超過 | `dueDate < today()` | 「超過 (M/D)」赤（`due-ov`） |
| 今日 | `dueDate === today()` | 「📅 今日」黄（`due-td`） |
| 今週中 | `today() < dueDate <= endOfWeekYmd()` | 「📅 M/D」緑（`due-fu`） |
| 来週以降 | `dueDate > endOfWeekYmd()` | 「📅 M/D」水（`due-far`） |
| 期限なし | `dueDate` 未設定 | バッジ非表示 |

### 開始バッジ（`startBadge`）

`b034381` で **完了済みも含めて常時表示** に変更。

| 状態 | 条件 | 表示 / 色 |
|---|---|---|
| 過去 | `startDate < today()` | 「▶ M/D」灰（`start-past`） |
| 今日 | `startDate === today()` | 「▶ 今日」黄（`start-td`） |
| 未来 | `startDate > today()` | 「▶ M/D」水（`start-fu`） |

### 同日統合バッジ（`sameDayBadge`）

開始日と終了日が同じ日の場合は「▶📅 今日」のように両アイコンを併記した1つのバッジになります。

### 繰り返しバッジ（`recurrenceBadge`）

`recurrence` 設定があるタスクには「🔁 毎日」「🔁 毎週月」「🔁 毎月末日」のようなグレー（`recurrence-badge`）のバッジが付きます。

> 日付バッジ色を変更する場合、サイドバーの件数丸も**必ずセットで変更**します（ユーザー記憶 `feedback_badge_color_sync.md`）。

## 繰り返しタスク（`b87a2bc`）

### データ構造

```javascript
recurrence?: {
  type: 'daily' | 'weekly' | 'monthly',
  weekday?: 0-6,        // type:'weekly' のとき、0=日〜6=土
  day?: 1-31 | 'last',  // type:'monthly' のとき、'last' は月末日
}
```

### 主要ヘルパー

- `addDaysYmd(ymd, n)` — YMD に日数加算
- `monthlyDateFor(year, month, day)` — 月末対応の月日付算出
- `computeFirstDueDate(recurrence, baseYmd)` — 繰り返し設定から最初の発生日
- `advanceRecurrenceDate(currentYmd, recurrence)` — 既存 `dueDate` から次回発生日へ
- `isoWeekKey(ymd)` / `getPeriodKey(ymd, type)` — 周期キー生成
- `applyRecurringResets()` — 周期境界をまたいだ完了タスクを未完了化＋次回 `dueDate` へ進める

### 周期境界リセット

`render()` の冒頭で `applyRecurringResets()` を呼びます。完了済みで `recurrence` を持つ todo について、「最後に完了した周期キー」と「今日の周期キー」が異なれば未完了化＋次回 `dueDate` へ自動更新。

- 毎日タスク: 翌日0時以降に開くと自動復活
- 毎週タスク: 次の ISO 週で自動復活
- 毎月タスク: 翌月で自動復活

### 編集 UI

- 編集画面の「繰り返し」セレクト: なし / 毎日 / 毎週 / 毎月
- 毎週選択 → 曜日セレクト（`WEEKDAY_LABELS = ['日','月','火','水','木','金','土']`）
- 毎月選択 → 日付セレクト（1〜31 + 末日）
- 繰り返し ON のとき `startDate` を自動クリア、開始日／終了日入力欄を非表示
- `commitEdit()` で `editRecurrence` がセットされていれば `computeFirstDueDate()` で `dueDate` を自動設定

### localStorage 互換性

旧データに `recurrence` がない場合はそのまま。`load()` で `typeof t.recurrence !== 'object'` ならクリアする型チェックあり（マイグレーション §4）。

## フィルターチップ（`2b506ff` / `42ec6f3` / `a3eab13`）

入力欄の下に5つのチップが並びます。state 変数は `taskFilter`（`all` / `week` / `actionable` / `overdue` / `today`）。

| キー | ラベル | 条件 |
|---|---|---|
| `all` | すべて | デフォルト |
| `week` | 📅 今週中 | `dueDate <= today+6日`（超過も含む） |
| `actionable` | ▶️ 着手可能 | `startDate <= today` または `startDate` なし |
| `overdue` | 🔥 超過 | `dueDate < today` |
| `today` | ⚡ 今日 | `dueDate === today` |

- 完了済みタスクはどのフィルターにも該当しない（`matchFilter()` で除外、`42ec6f3`）
- フィルター中は完了セクションも非表示
- グループ単位でフィルター: メインまたはサブのいずれかが条件一致ならグループ全体を残す
- **サブの表示判定**（`a3eab13`）: 親が残るだけではサブは表示されない。サブ自身もフィルター条件を満たす必要がある

メモリスト（`list.type === 'memo'`）ではフィルターチップは非表示。

> 以前は「すべて／未完了／完了」の3タブフィルターでしたが、完了セクションとチップフィルターに置き換えられ廃止されました。

## 完了セクション

完了済みタスクは下部の折りたたみセクション「▶ 完了 (N件)」に集約されます（`showCompletedSection` state、`data-a="toggle-completed-section"`）。`▶` / `▽` のキャレットは `chevronRight` SVG を `.expanded` クラスで90°回転して使い回し。

フィルター適用中は完了セクション自体が非表示になります。

### サブグループ内の完了サブ

親メインが未完了で、未完了サブの後ろに完了サブが残っているとき、「▷ 完了 (N件)」というインライントグルが描画され、開閉できます（`expandedDoneSubs: Set<string>`）。詳細は [02-1 タスクとリスト管理](02-1_タスクとリスト管理.md)。

## 描画順序（`arrangeForRender`）

フィルター適用後のリストを `arrangeForRender(visibleList)` に渡し、**「メイン → そのサブ群」の順に整列**します。`collapsedIds` に含まれるメインのサブは結果から除外され、必要に応じて完了サブヘッダーが挟まれます。

## ステータスドット（サイドバー）

`showListStats` の ON/OFF はサイドバーの目アイコンで切替（`toggleListStats()`）。`todo-app-show-stats` キーに永続化。

ドットは `listStats()` の各カテゴリ件数に対応した色で表示されます。詳細は [02-1 タスクとリスト管理](02-1_タスクとリスト管理.md) の「ステータスドット / 緊急度カラー」。

## リスト折りたたみ

サイドバーのリストが `LIST_COLLAPSE_LIMIT = 5` 件を超えると折りたたみ。`listExpanded` トグル（`toggleListExpand`）で展開／折りたたみ。**選択中のリストは折りたたみ時も必ず表示**されます。

## 全て折り畳み / 全て展開（`21ce223`）

リストヘッダーに「全て折り畳む / 全て展開する」ボタン（`.collapse-all-btn`）があり、現在リストのサブ持ちメインすべてを一括で開閉できます。アイコンは `chevronRight` を `.expanded` クラスで回転。hover ツールチップあり。

## ダークモード

- `<head>` 内のインラインスクリプトで `localStorage.darkMode` を読み、即時 `<html class="dark">` を付与（FOUC回避）。
- 既定は ON（`s !== null ? s === 'true' : true`）。
- `toggleDark()` で反転、`localStorage.darkMode` を保存。
- localStorage キーは `darkMode`（プレフィックスなし、レガシー名）。
