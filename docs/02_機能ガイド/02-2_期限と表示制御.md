# 02-2 期限と表示制御

## 期限日の保存形式

タスクの `dueDate` は `'YYYY-MM-DD'` 文字列で保存されます。日付の比較・生成は **ローカル時刻ベース** で行います。

```javascript
const ymd = (d) => `${d.getFullYear()}-${String(d.getMonth()+1).padStart(2,'0')}-${String(d.getDate()).padStart(2,'0')}`;
const today    = () => ymd(new Date());
const tomorrow = () => ymd(new Date(Date.now() + 86400000));
```

> 以前は `toISOString().slice(0,10)` でUTC基準だったため、JST深夜0時〜9時に期限切れ判定がずれるバグがありました（コミット `9ab45b4` で修正、[HANDOFF.md](../../HANDOFF.md)）。詳細は [05-2 既知の制約とハマりどころ](../05_リファレンス/05-2_既知の制約とハマりどころ.md)。

## 期限日バッジ

タスク行右側にバッジが表示されます。色はカテゴリで切替（カテゴリ判定は `listStats()` と同じロジック）。

| 状態 | 条件 | 意味 |
|---|---|---|
| 期限切れ | `dueDate < today()` | 過去日 |
| 今日 | `dueDate === today()` | 本日締切 |
| 未来 | `dueDate > today()` | 将来 |
| 期限なし | `dueDate` 未設定 | バッジ非表示 |

> 日付バッジ色を変更する場合、サイドバーの件数丸（カラードット）も**必ずセットで変更**します（ユーザー記憶 `feedback_badge_color_sync.md`）。

## 開始日（`startDate`）

タスクには `startDate?: string`（`'YYYY-MM-DD'`）を持たせられます。メイン／サブどちらでも設定可能。編集UIには「クリア」ボタン（`data-a="clr-start-date"`）が付属します。

- **未来日（今日より後）の開始日は、その日まで「開始日: MM/DD」のラベルを行内に表示**
- 開始日が **過ぎた／未設定** タスクはラベル非表示
- 完了済み・編集中のタスクには表示しない
- 開始日が今日の場合は強調表示（`is-today`）

実装は `htmlMain()` の `t.startDate && !t.completed && !editing` 分岐（[TList.html:1325-1335 付近](../../TList.html)）。

## 完了日時（`completedAt`）

`toggleTodo()` でチェックON時に `Date.now()` を自動セット、OFFで `undefined` に戻します（[TList.html:1603-1604](../../TList.html)）。

完了済みタスクには本文テキスト下に「✓ MM/DD HH:mm 完了」が表示されます。

> 機能追加以前から完了済みになっていたタスクには `completedAt` が無いため、完了日時ラベルは表示されません（新規に完了→未完了→完了し直すと表示されるようになります）。

## フィルター

`filter` グローバル変数で切替（`htmlMain()` 内 `filter === f.key` 判定）。

| 値 | 表示対象 |
|---|---|
| `'all'` | 全件 |
| `'active'` | 未完了のみ |
| `'completed'` | 完了のみ |

メモリスト（`list.type === 'memo'`）ではフィルターは非表示。`filtered(isMemo)` 関数で分岐します。

### フィルター時の親子強制表示

サブタスク導入に伴い、`filtered(isMemo)` はフィルター結果に対して以下の補正を行います（[TList.html:1037-1051](../../TList.html)）。

1. サブが条件にマッチした場合 → その **親メインを強制的に表示**（文脈維持のため）
2. メインが条件にマッチした場合 → その **配下のサブを全て表示**（折りたたみ判定は別レイヤー）

これにより、例えば「完了」フィルター中でも未完了のサブを持つ完了メインが見える、といった挙動になります。

### 描画順序（`arrangeForRender`）

`filtered()` 通過後のリストを `arrangeForRender(visibleList)` に渡し、**「メイン → そのサブ群」の順に整列**します。`collapsedIds` に含まれるメインのサブは結果から除外されます（[TList.html:1055-1077](../../TList.html)）。メモリストではこの整列を行いません。

## ステータスドット（サイドバー）

`showListStats` の ON/OFF はサイドバーの目アイコンで切替（`toggleListStats()`）。`todo-app-show-stats` キーに永続化。

ドットは `listStats()` の各カテゴリ件数に対応した色で表示されます。

## 先頭追加 / 自動整列

通常リストのみで利用可能（[TList.html:1256](../../TList.html) `!isMemoList` ガード）。

| トグル | 既定 | 永続化キー | 動作 |
|---|---|---|---|
| 先頭追加 | OFF（末尾） | `todo-app-add-to-top` | 新規タスクをリスト先頭に追加 |
| 自動整列 | OFF | `todo-app-auto-sort` | 期限日順にソート（ON切替時に `sortTodos()` 実行） |

## リスト折りたたみ

サイドバーのリストが `LIST_COLLAPSE_LIMIT = 5` 件を超えると折りたたみ。`listExpanded` トグル（`toggleListExpand`）で展開／折りたたみ。**選択中のリストは折りたたみ時も必ず表示**されます。

## ダークモード

- `<head>` 内のインラインスクリプトで `localStorage.darkMode` を読み、即時 `<html class="dark">` を付与（FOUC回避、[TList.html:63](../../TList.html)）。
- 既定は ON（`s !== null ? s === 'true' : true`）。
- `toggleDark()` で反転、`localStorage.darkMode` を保存。
