# 02-3 ドラッグドロップ操作

## 操作一覧

| 対象 | 操作 | 環境 | 結果 |
|---|---|---|---|
| タスク | グリップアイコンをドラッグ | デスクトップ | 同リスト内で並び替え |
| タスク（メイン → メイン行下60%） | ドラッグ＆ドロップ | デスクトップ | サブ化（`parentId` をターゲットに付与） |
| タスク（サブ → メイン行上40%） | ドラッグ＆ドロップ | デスクトップ | メイン化（`parentId` を解除） |
| タスク（サブ → 別メイン行下60%） | ドラッグ＆ドロップ | デスクトップ | 親変更（`parentId` を差し替え） |
| タスク（サブ） | 右クリック→メインに昇格 / モバイル長押し→「⬆️ メインに昇格」 | 両方 | `promoteSubToMain(id)`（`parentId` クリア） |
| タスク | サイドバーのリスト名へドラッグ | デスクトップ | リスト間移動（メインならサブも追従、サブ単体ならメイン化、`831c546`） |
| タスク | ゴミ箱ボタンへドラッグ | デスクトップ | 削除（`trash` 行き。メインならサブもペア移動） |
| リスト | サイドバーで上下にドラッグ | デスクトップ | リスト並び替え |
| タスク | グリップを長押し | モバイル | タッチ並び替え |
| タスク | タスク本体を長押し | モバイル | リスト移動ポップアップ表示（サブなら「⬆️ メインに昇格」も） |
| タスク | 右クリック | デスクトップ | コンテキストメニュー（編集/サブに登録▶/メインに昇格/削除） |
| リスト | 右クリック or ドラッグハンドル以外を長押し | 両方 | 名前変更 / リスト削除 |
| ファイル | JSONファイルをウインドウへドロップ | デスクトップ | インポートモーダル起動 |

> 以前は「ゴミ箱内タスクをフィルターボタンへドラッグして状態指定して復元」できましたが、フィルターチップ刷新により廃止されました。復元はゴミ箱パネルの復元ボタンから行います。

## メイン⇔サブ変換のドロップ位置判定

タスク行にドロップする際、行内のY座標で **サブ化／並び替え／メイン化** を切り分けます。

```javascript
const rect = onTodo.getBoundingClientRect();
const isSubZone = (e.clientY - rect.top) > rect.height * 0.6; // 行の下 40% がサブゾーン
```

判定マトリクス:

| ドラッグ元 | ターゲット | ドロップ位置 | 結果 |
|---|---|---|---|
| メイン（サブ無し） | 別メイン | 下60% (subZone) | サブ化（`parentId = ターゲット`、ターゲットの折りたたみは解除） |
| メイン（サブ有り） | 別メイン | 下60% (subZone) | **サブ化拒否**（並び替えのみ。サブのサブを禁止するため） |
| サブ | 別メイン | 下60% (subZone) | 親差し替え（`parentId = 別メイン`） |
| サブ | メイン | 上40% | メイン化（`parentId = undefined`）＋並び替え |
| メイン | メイン | 上40% | 通常の並び替え |
| サブ | サブ | 任意 | 並び替え（親子関係は変えない、または上位ロジックに従う） |

ドラッグ中、サブ化候補のターゲット行には `drop-as-sub` クラスが付与され視覚フィードバックされます。**サブ化対象は親メインの末尾に固定挿入** されます（`9e54034`）。

## デスクトップ／モバイル判定

```javascript
const hasTouch = 'ontouchstart' in window;
// ドラッグ可否
draggable="${!editing && !hasTouch}"
```

`hasTouch === true` の環境では HTML5 D&D を抑制し、タッチ用の長押しUIを採用します。

## モバイル: リスト移動ポップアップ

タスクの長押しで `showMovePopup(todoId)` が呼ばれ、リスト一覧から移動先を選択できます。サブタスクの場合は同ポップアップ内に **「⬆️ メインに昇格」** が追加表示されます（`promoteSubToMain(id)`）。

タッチ誤作動防止のため、ポップアップを開いた直後 **400msのガード** を入れています。

```javascript
let movePopupOpenedAt = 0;
function showMovePopup(todoId) {
  movePopupTodoId = todoId;
  movePopupOpenedAt = Date.now();
  render();
}
function closeMovePopup() {
  if (Date.now() - movePopupOpenedAt < 400) return;
  movePopupTodoId = null;
  render();
}
```

## ファイルD&D（インポート）

ウインドウ全体に `dragenter/dragleave/drop` リスナを設定。`fileDragOver` フラグでオーバーレイを表示し、JSON以外ははじきます。

```javascript
if (!file.name.endsWith('.json')) { alert('JSONファイルのみインポート可能です。'); return; }
```

## Tauri環境での重要設定

**`tauri.conf.json` の `app.windows[0].dragDropEnabled` は `false`** にしています。これは Tauri 既定のネイティブD&Dハンドラを無効化することで、ブラウザ側のHTML5 D&D（リスト間移動・ゴミ箱投入）を機能させるためです（[tauri.conf.json](../../tauri/src-tauri/tauri.conf.json)）。

```json
"app": {
  "windows": [{
    "dragDropEnabled": false
  }]
}
```

詳細・他のネイティブ環境特有の落とし穴は [05-2 既知の制約とハマりどころ](../05_リファレンス/05-2_既知の制約とハマりどころ.md) を参照。
