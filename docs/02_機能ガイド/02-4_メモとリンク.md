# 02-4 メモとリンク

タスクには **詳細メモ（`detail`）** と **フォルダパスまたはURL（`folderPath` + `linkType`）** を紐付けられます。

## フォルダ／URL の登録

タスク編集モードで以下を設定できます。

| フィールド | 型 | 用途 |
|---|---|---|
| `folderPath` | string | パス文字列（フォルダ／URL の双方を保持） |
| `linkType` | `'folder'` \| `'url'` | パスの種類。空文字なら未設定 |

`linkType === 'url'` ならリンクアイコン（`I.link`）、それ以外はフォルダアイコン（`I.folder`）が表示されます。

### デスクトップ専用ボタン（URLは例外）

タスク行のフォルダボタンは **デスクトップ環境のみ表示** されます（`!hasTouch && t.folderPath`）。一方、`linkType === 'url'` の URL ボタンは **タッチ環境でも表示** されます（モバイルでもブラウザで開けるため、`9e54034`）。

## ボタンを押したときの挙動

`folder-open` ハンドラ内で環境を自動判定し、適切な手段でフォルダ／URLを開きます。

| 種類 | 優先順 |
|---|---|
| URL（`linkType === 'url'`） | Tauri → `window.open()` |
| フォルダ | Tauri → クリップボードコピー（Web） |

実装詳細は [04-3 ネイティブ環境連携](../04_実装詳細/04-3_ネイティブ環境連携.md) を参照。

## 詳細メモ（`detail`）

複数行のテキストをタスクに紐付けます。`detail` がセットされたタスクには「メモボタン」が表示され、タップでポップアップ表示されます。

### メモポップアップの位置計算

`htmlMemoPopup()` で動的に位置を決定（[HANDOFF.md](../../HANDOFF.md) §「メモポップアップの配置ロジック」より）。

| 項目 | ロジック |
|---|---|
| 縦位置 | ボタン下に120px以上のスペースがあれば下、なければ上に表示 |
| `max-height` | 選択方向の利用可能スペースに応じて設定（最低100px保証） |
| 水平位置 | ボタン中央寄せ、画面端でクランプ |
| 幅 | `min(500px, 100vw - 32px)` |

### ポップアップ内SVGのサイズ制限

メモポップアップ内のSVGは、明示的にCSSでサイズを指定しないと大きく表示されることがあります。

```css
.memo-popup-label svg { width:11px; height:11px; flex-shrink:0; }
```

詳細は [05-2 既知の制約とハマりどころ](../05_リファレンス/05-2_既知の制約とハマりどころ.md)。

## 関連状態

| 変数 | 意味 |
|---|---|
| `memoPopupId` | 開いているメモポップアップのタスクID |
| `memoPopupPos` | ポップアップ位置（計算結果） |
