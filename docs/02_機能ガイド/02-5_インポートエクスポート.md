# 02-5 インポートエクスポート

`localStorage` のデータをJSONで書き出し／読み込みします。3方式（Web／Electron／Tauri／Photino）間ではデータが共有されないため、**移行はこのJSONを介して行います**。

## エクスポートJSON形式

`executeExport()` で生成（[TList.html:1733](../../TList.html)）。

```json
{
  "version": 1,
  "exportedAt": "2026-05-08T12:34:56.789Z",
  "lists": [
    { "id": "...", "name": "マイタスク", "createdAt": 1700000000000 }
  ],
  "todos": [
    {
      "id": "...",
      "text": "...",
      "completed": false,
      "createdAt": 1700000000000,
      "listId": "...",
      "dueDate": "2026-05-10",
      "startDate": "2026-05-09",
      "folderPath": "C:\\path",
      "linkType": "folder",
      "detail": "...",
      "parentId": "...",
      "completedAt": 1700000000000
    }
  ],
  "trash": [ ... ]
}
```

> 内部用フィールド `_trashedWithParent` は `executeExport()` 内の `stripInternal()` で除去されます（[TList.html:1910](../../TList.html)）。

### サブタスクのインポート

インポート時、旧ID → 新ID のマップを `todoIdMap` で構築し、`parentId` も新IDに置換します。インポート対象に親メインが含まれない孤児サブは `parentId` を削除してメインとして取り込みます（[TList.html:1982-2011](../../TList.html)）。`trash` 側の `_trashedWithParent` や `parentId` は取り込み時に削除されます。

ファイル名: `tasks-{YYYY-MM-DD}.json`（例: `tasks-2026-05-08.json`）。

## エクスポート操作

1. メニューから「エクスポート」を選択 → モーダル起動（`openExportModal()`）
2. リスト一覧が表示され、チェックで対象を選択（**既定は全件チェック**）
3. 「エクスポート (N)」ボタンで `executeExport()` 実行
4. 選択したリストに属するタスク・ゴミ箱項目のみが書き出される

`payload` の `lists` / `todos` / `trash` は、選択された `listId` で絞り込まれます。

## インポート操作

3つのトリガーがあります。

| トリガー | 起点 |
|---|---|
| メニュー → インポート | `openImportModal()` がファイル選択ダイアログを起動 |
| ファイルD&D | ウインドウ全体に `.json` ファイルをドロップ |

ファイル読み込み後 `processImportFile(text)` でパース → `validateImportData()` でバリデーション → モーダルでリスト単位選択 → 選択したリストのみ取り込み。

```javascript
if (!file.name.endsWith('.json')) { alert('JSONファイルのみインポート可能です。'); return; }
```

### インポート時の挙動

- リストの `type`（`'memo'` 等）は **インポート時に保持** されます（コミット `bbdc065`）。
- 既存リストとIDが衝突する場合の挙動は `validateImportData()` / モーダル選択の結果に依存します。

## バリデーション

`validateImportData(data)` で `data.lists` の存在等を最低限チェック。失敗時は「無効なファイル形式です。」アラート。

## モーダル状態

| 変数 | 意味 |
|---|---|
| `modalMode` | `'export'` \| `'import'` |
| `modalLists` | モーダル内のリスト + チェック状態 |
| `modalAllChecked` | 全選択フラグ |
| `importPayload` | インポート対象のJSONペイロード |
