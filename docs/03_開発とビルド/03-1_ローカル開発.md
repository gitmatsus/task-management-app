# 03-1 ローカル開発

`TList.html` は外部依存ゼロの単一HTMLなので、特別な開発サーバを必要としません。

## 起動方法

### モード1: 直接ブラウザで開く

ファイルをダブルクリック、もしくはブラウザに `file://` でドロップ。

- 利点: 何も用意しなくてよい
- 欠点: `file://` で `crypto.randomUUID()` 等が一部ブラウザで制限される場合あり、`fetch` 系が動かないなど

### モード2: ローカルサーバ経由

```bash
# プロジェクトルートで
npx serve
# または
python -m http.server 8000
```

ブラウザで `http://localhost:3000/TList.html`（serve の既定ポート）等にアクセス。

- 推奨。`http://` 経由で本番に近い挙動になります。

### モード3: GitHub Pages

公開URL: <https://gitmatsus.github.io/task-management-app/app.html>

`app.html` は `TList.html` へのリダイレクトです（コミット `ec731e0`、`d8475ed`）。

## モバイル動作確認

スマホ実機でアクセスする場合は同一LAN上のPCで `npx serve` し、`http://<PCのIP>:3000/TList.html` にスマホからアクセスします。

- iOS: `font-size: 16px` 未満の入力欄でズームが起きるため、`@media (max-width:640px)` で `.edit-text { font-size:16px; }` を保証（[TList.html](../../TList.html) CSS）。
- セーフエリア対応: `env(safe-area-inset-*)` でDynamic Island周りを回避。

## 編集ワークフロー

`TList.html` を直接編集 → ブラウザリロードで反映。

Tauri 版で確認する場合は、`tauri/package.json` の `predev` / `prebuild` スクリプトで `TList.html` が `tauri/dist/index.html` に自動コピーされます。`TList.html` を編集したら `npm run dev` を再起動。

ネイティブ版の起動・ビルドは [03-2 Tauri パッケージング](03-2_ネイティブパッケージング.md) を参照。
