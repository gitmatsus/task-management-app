# 03-2 Tauri パッケージング

`TList.html` を **Tauri v2** で包んで Windows ネイティブアプリ化します。配布サイズ ~10MB、起動高速、WebView2 標準利用。旧 Electron / Photino 対応は撤廃済み。

## 概要

| 項目 | 値 |
|---|---|
| フレームワーク | Tauri v2 (`@tauri-apps/cli` v2) |
| バックエンド | Rust + `windows` クレート / WebView2 |
| 配布形態 | NSIS インストーラ（`.exe`） |
| 期待サイズ | 10MB 前後 |
| 状態 | dev 起動確認済み・配布ビルド未実施（[HANDOFF.md](../../HANDOFF.md) §「未実装・検討事項」） |

## ファイル構成

```
tauri/
├── package.json              ← @tauri-apps/cli v2 / sync-html
├── dist/index.html           ← TList.html のコピー（predev/prebuild で自動同期）
├── app-icon.png              ← アイコン元画像
└── src-tauri/
    ├── Cargo.toml            ← tauri v2, serde
    ├── build.rs
    ├── tauri.conf.json       ← withGlobalTauri / dragDropEnabled:false / NSIS
    ├── capabilities/
    │   └── default.json      ← core:default
    ├── icons/                ← tauri icon 生成済み
    └── src/main.rs           ← open_folder コマンド + WebView2 追加引数設定
```

## 起動・ビルド

```bash
cd tauri
npm install      # 初回のみ
npm run dev      # 開発起動（初回 5〜10 分、2回目以降数秒）
npm run build    # 配布ビルド → src-tauri/target/release/bundle/nsis/
```

## 前提条件

- **Rust** (`rustup-init.exe` でインストール)
- **VS C++ Build Tools**（VS Installer の「C++によるデスクトップ開発」ワークロード）
- **Node.js** v24 以上
- **WebView2 Runtime**（Windows 11 標準搭載、Windows 10 は別途インストール）

## HTML 自動同期

`tauri/package.json` の `predev` / `prebuild` スクリプトで `TList.html` → `dist/index.html` にコピー。

```json
"sync-html": "node -e \"require('fs').copyFileSync('../TList.html','dist/index.html');console.log('copied TList.html -> dist/index.html')\""
```

`TList.html` を編集したら `npm run dev` を再起動して反映。

## Rust 側（`src-tauri/src/main.rs`）の主要部分

```rust
// Edge ミニメニュー（翻訳ボタン等）の抑制
#[cfg(target_os = "windows")]
std::env::set_var(
    "WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS",
    "--disable-features=msEdgeMiniMenu,msEdgeAskMeAnything,TextSuggestionsForMiniMenu",
);

// open_folder コマンド: cmd /C start でURL/フォルダ/ファイルをOS既定アプリで開く
// CREATE_NO_WINDOW フラグでコンソール非表示
#[tauri::command]
fn open_folder(path: String) -> Result<(), String> {
    Command::new("cmd")
        .args(["/C", "start", "", &path])
        .creation_flags(CREATE_NO_WINDOW)
        .spawn()
        .map_err(|e| e.to_string())?;
    Ok(())
}
```

## 重要設定（`tauri.conf.json`）

- `app.withGlobalTauri: true` — `window.__TAURI__` をブラウザJSから直接見えるようにする
- `app.windows[0].dragDropEnabled: false` — Tauri 既定のネイティブD&Dハンドラを無効化し、ブラウザ側の HTML5 D&D（リスト間移動・ゴミ箱投入）を機能させる（[02-3 ドラッグドロップ操作](../02_機能ガイド/02-3_ドラッグドロップ操作.md)）
- バンドラは `nsis`（Windows インストーラ）

## アイコン生成（初回のみ）

ベース画像（1024×1024 以上の `.png`）を用意して以下を実行:

```bash
npm run tauri icon path\to\icon.png
```

`src-tauri/icons/` 配下に必要なサイズのアイコンが自動生成されます。

## データ保存先

| 環境 | localStorage 保存先 |
|---|---|
| Web (ブラウザ) | 各ブラウザの localStorage 領域（ドメイン単位） |
| Tauri | `%APPDATA%\com.tlist.app\EBWebView\` 配下（WebView2） |

ブラウザ版と Tauri 版で localStorage は **共有されません**。データ移行は [02-5 インポートエクスポート](../02_機能ガイド/02-5_インポートエクスポート.md) のJSONを介して行います。
