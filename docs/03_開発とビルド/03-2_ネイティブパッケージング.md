# 03-2 ネイティブパッケージング

`TList.html` を3種類のフレームワークで包んでネイティブアプリ化できます。最終選定（[HANDOFF.md](../../HANDOFF.md)「未実装・検討事項」）は未実施。

## 比較表

| 方式 | 配布サイズ（見込み） | 起動コマンド | ビルド出力 | 状態 |
|---|---|---|---|---|
| Electron | 150〜200MB | `npm start` | NSIS インストーラ（`dist/`） | 動作確認済み |
| Tauri | 3〜10MB | `npm run dev` | NSIS（`src-tauri/target/release/bundle/nsis/`） | dev起動確認済み・配布ビルド未実施 |
| Photino | 15〜30MB | `dotnet run` | 単一exe（`dotnet publish`） | ビルド成功・起動確認中 |

## Electron

### ファイル

```
electron/
├── main.js       ← Electronメインプロセス（shell.openPath）
├── preload.js    ← contextBridge 経由で API 公開
├── package.json  ← electron v35 / electron-builder v25
└── build.bat     ← ビルドヘルパー
```

### 起動・ビルド

```bash
cd electron
npm install      # 初回のみ
npm start        # 開発起動
npm run build    # dist/ にインストーラ生成
```

### パス解決

```javascript
const htmlPath = app.isPackaged
  ? path.join(process.resourcesPath, 'TList.html')   // インストール後
  : path.join(__dirname, '..', 'TList.html');         // 開発時
```

### 設定ハイライト

- `Menu.setApplicationMenu(null)` でメニューバー非表示
- `requestSingleInstanceLock()` で二重起動防止 + 既存ウインドウフォーカス
- `contextIsolation: true`, `nodeIntegration: false`（セキュリティ既定）
- `extraResources` で `../TList.html` をインストーラに同梱

## Tauri (v2)

### ファイル

```
tauri/
├── package.json              ← @tauri-apps/cli v2 / sync-html
├── dist/index.html           ← TList.html のコピー（自動同期）
└── src-tauri/
    ├── Cargo.toml            ← tauri v2, serde
    ├── tauri.conf.json       ← withGlobalTauri / dragDropEnabled:false
    ├── capabilities/default.json
    ├── icons/                ← tauri icon 生成済み
    └── src/main.rs           ← open_folder コマンド
```

### 起動・ビルド

```bash
cd tauri
npm install      # 初回のみ
npm run dev      # 開発起動（初回5〜10分、2回目以降数秒）
npm run build    # 配布ビルド → src-tauri/target/release/bundle/nsis/
```

### 前提条件

- Rust（`rustup-init.exe`）
- VS C++ Build Tools（VS Installer →「C++によるデスクトップ開発」）
- Node.js v24
- WebView2 Runtime（Windows 11 標準搭載）

### HTML同期

`package.json` の `predev` / `prebuild` で `TList.html` → `dist/index.html` にコピー。

```json
"sync-html": "node -e \"require('fs').copyFileSync('../TList.html','dist/index.html');console.log('copied TList.html -> dist/index.html')\""
```

### 重要設定

- `app.withGlobalTauri: true` → `window.__TAURI__` をグローバル注入
- **`app.windows[0].dragDropEnabled: false`** → ブラウザ側のHTML5 D&Dを有効化（[02-3](../02_機能ガイド/02-3_ドラッグドロップ操作.md)）

## Photino (.NET)

### ファイル

```
photino/
├── TList.csproj    ← Photino.NET 4.* / net9.0 / SingleFile / SelfContained
├── Program.cs      ← PhotinoWindow + メッセージハンドラ
└── icon.ico
```

### 起動・ビルド

```bash
cd photino
dotnet run         # 開発起動
dotnet publish     # 配布用単一exe（未実施）
```

### 前提条件

- .NET 9.0 SDK

### C#側メッセージハンドラ

```csharp
window.RegisterWebMessageReceivedHandler((sender, message) => {
    if (message.StartsWith("open-folder:")) {
        var path = message["open-folder:".Length..];
        Process.Start(new ProcessStartInfo { FileName = path, UseShellExecute = true });
        window.SendWebMessage("folder-result:success");
    } else if (message.StartsWith("open-url:")) {
        // 同様
    }
});
```

### HTMLコピー

csproj の `CopyHtml` ターゲットでビルド後に `TList.html` を出力ディレクトリへコピー。**日本語パスの問題で `Content Include` ではなく `Exec Command="copy"` を使用** しています。

### アイコン設定

- `<ApplicationIcon>icon.ico</ApplicationIcon>`（csproj）
- `.SetIconFile(iconPath)`（Program.cs）

**両方** が必要（[05-2](../05_リファレンス/05-2_既知の制約とハマりどころ.md)）。

### 名前空間

- `using Photino.NET;`（正しい）
- `using PhotinoNET;`（古い情報・誤り）

## データの非共有

3方式間で `localStorage` は **共有されません**。移行は [02-5 インポートエクスポート](../02_機能ガイド/02-5_インポートエクスポート.md) で。

| 環境 | localStorage 保存先 |
|---|---|
| Electron | Electron独自パス |
| Tauri | `%APPDATA%\com.tlist.app\EBWebView\` 配下（WebView2） |
| Photino | WebView2 の既定パス |
