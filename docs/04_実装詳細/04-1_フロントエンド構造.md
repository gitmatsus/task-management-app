# 04-1 フロントエンド構造

`TList.html` はおよそ 3300 行の単一ファイル。`<style>` → `<body>` → 大きな `<script>` ブロックの構成です。最新の網羅情報は [HANDOFF.md](../../HANDOFF.md) を一次情報源とし、本章はその要約＋章別の入り口として整理しています。

## 描画モデル

**全体再描画方式** を採用。状態を変えたら `render()` を呼ぶだけ。

```javascript
function html() {
  // サイドバー + メイン + モーダル + 各種ポップアップ + ドロップゾーン を結合した文字列を返す
  return htmlSidebar() + htmlMain() + htmlModal() + htmlMovePopup() + htmlMemoPopup() + htmlCtxMenu() + dropZone;
}
function render() {
  applyRecurringResets();   // 繰り返しタスクの周期境界リセット（先に行う）
  document.getElementById('app').innerHTML = html();
  // 必要に応じてフォーカス復元・イベントリバインドを実施
}
```

DOMの差分計算はしません。`<input>` / `<textarea>` のフォーカスは描画後に復元（`skipFocusRestore` フラグで抑制可）。

## イベント委譲

`document.addEventListener('click', ...)` 等で **委譲方式** を採用。各要素には `data-a="..."` 属性でアクションIDを持たせます。

```javascript
const el = e.target.closest('[data-a]');
const a = el?.dataset.a;
// switch (a) { case 'toggle-todo': ...; case 'folder-open': ...; ... }
```

主な `data-a` アクション（抜粋）:

| アクション | 用途 |

| `select-list` / `del-list` | リスト選択 / 削除 |
| `start-add-list` | 新規リスト追加開始 |
| `toggle-collapse` | サブを持つメインの折りたたみトグル |

## 主要 HTML 生成関数

| 関数 | 役割 |
|---|---|
| `htmlSidebar()` | リスト一覧、ステータスドット、ゴミ箱ボタン、エクスポート/インポートUI |
| `htmlMain()` | メインカラム（入力欄・フィルターチップ・タスクリスト・完了セクション・ゴミ箱表示） |
| `htmlModal()` | インポート／エクスポートモーダル |
| `htmlMovePopup()` | モバイル長押し時のリスト移動ポップアップ |
| `htmlMemoPopup()` | 詳細メモポップアップ |
| `htmlCtxMenu()` | 右クリック/長押しコンテキストメニュー（タスク/リスト両対応） |
| `html()` | 上記を結合 |
| `render()` | `applyRecurringResets()` → `app.innerHTML = html()` |

## 主要ヘルパー関数（カテゴリ別）

### 日付・周期

| 関数 | 役割 |
|---|---|
| `ymd(d)` | Date → `'YYYY-MM-DD'`（ローカル時刻） |
| `today()` / `tomorrow()` / `endOfWeekYmd()` | 今日／明日／今週末の YMD |
| `addDaysYmd(ymd, n)` | YMD に日数加算 |
| `monthlyDateFor(year, month, day)` | 月末対応の月日付算出（`'last'` 対応） |
| `computeFirstDueDate(recurrence, baseYmd)` | 繰り返しの最初の発生日 |
| `advanceRecurrenceDate(currentYmd, recurrence)` | 既存 `dueDate` から次回発生日へ |
| `isoWeekKey(ymd)` / `getPeriodKey(ymd, type)` | 周期キー生成 |
| `applyRecurringResets()` | 周期境界をまたいだ完了タスクを未完了化＋次回へ進める |

### タスク・サブタスク

| 関数 | 役割 |
|---|---|
| `currentTodos()` / `currentTrash()` | 選択中リストのタスク・ゴミ箱 |
| `listStats(lid)` | リスト統計（total/active/done/overdue/dueToday/dueWeek/weekPlus/future/noDate） |
| `subTodosOf(parentId)` / `hasSubs(id)` / `isSubTask(t)` / `getParent(t)` | サブタスク関係 |
| `splitGroupsByCompletion()` | active / completed グループに振り分け（親完了でも未完了サブが残れば active 側） |
| `matchFilter(t)` | フィルターチップ条件への一致判定 |
| `applyTaskFilter(list, keepMainIds)` | フィルター適用（サブは自身もマッチが必須、`a3eab13`） |
| `arrangeForRender(visibleList)` | 「メイン→そのサブ群」順に整列、`collapsedIds`・`expandedDoneSubs` 反映 |
| `promoteSubToMain(id)` | サブをメインに昇格 |
| `moveToTrash(id)` | タスクをゴミ箱へ移動（親なら子もペア移動） |

### 状態・編集

| 関数 | 役割 |

## モバイル判定

```javascript
function isMobile() {
  return window.innerWidth <= 640 ||
    ('ontouchstart' in window && window.innerWidth <= 1024);
}
const hasTouch = 'ontouchstart' in window;
```

- `isMobile()` はレイアウト分岐用
- `hasTouch` はドラッグ可否・デスクトップ専用UIの出し分け用

## デスクトップ専用UIの出し分け

```javascript
draggable="${!editing && !hasTouch}"
// URLボタンは linkType='url' なら touch でも表示
${t.folderPath && !editing && (t.linkType === 'url' || !hasTouch) ? `<button data-a="folder-open" ...>` : ''}
```

`+` ボタン（サブ追加）は CSS の `@media (hover: none)` でタッチ環境では常時表示にしています（`9e54034`）。
