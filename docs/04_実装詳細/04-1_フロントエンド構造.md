# 04-1 フロントエンド構造

`TList.html` はおよそ2360行の単一ファイル。`<style>` → `<body>` → 大きな `<script>` ブロックの構成です。

## 描画モデル

**全体再描画方式** を採用。状態を変えたら `render()` を呼ぶだけ。

```javascript
function html() {
  // サイドバー + メイン + モーダル + メモポップアップ + ドロップゾーン を結合した文字列を返す
  return htmlSidebar() + htmlMain() + htmlModal() + htmlMovePopup() + htmlMemoPopup() + dropZone;
}
function render() {
  document.getElementById('app').innerHTML = html();
  // 必要に応じてフォーカス復元・イベントリバインドを実施
}
```

DOMの差分計算はしません。`<input>` / `<textarea>` のフォーカスは描画後に復元（`skipFocusRestore` フラグで抑制可）。

## イベント委譲

`document.addEventListener('click', ...)` 等で **委譲方式** を採用。各要素には `data-a="..."` 属性でアクションIDを持たせます。

```javascript
const el = e.target.closest('[data-a]');
const a = el?.dataset.a;
// switch (a) { case 'toggle-add-top': ...; case 'folder-open': ...; ... }
```

主なアクション例: `folder-open`, `toggle-add-top`, `toggle-auto-sort`, `modal-toggle`, `modal-confirm`, `drag-handle` ほか。

サブタスク／開始日関連で追加された `data-a`:

| アクション | 用途 |
|---|---|
| `toggle-collapse` | サブを持つメインの折りたたみトグル（`collapsedIds` Set を反転） |
| `clr-start-date` | 編集UIで開始日入力をクリア |
| `promote-to-main` | モバイル長押しメニューでサブをメインに昇格 |

## SVGアイコン

`const I = { ... }` オブジェクトに全アイコンを定義。利用時は `I.folder`, `I.memo`, `I.notepad`, `I.clip`, `I.grip`, `I.link`, `I.upload`, `I.arrowUp` などを直接埋め込みます。

## モバイル判定

```javascript
function isMobile() {
  return window.innerWidth <= 640 ||
    ('ontouchstart' in window && window.innerWidth <= 1024);
}
const hasTouch = 'ontouchstart' in window;
```

- `isMobile()` はレイアウト分岐用
- `hasTouch` はドラッグ可否・デスクトップ専用UIの出し分け用

## デスクトップ専用UIの出し分け

```javascript
draggable="${!editing && !hasTouch}"
${!hasTouch && t.folderPath ? `<div class="item-folder">...` : ''}
```
