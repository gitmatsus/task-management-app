## タスク構造（`todos` の要素）

```javascript
{
  id: string,           // crypto.randomUUID()
  text: string,
  completed: boolean,
  createdAt: number,    // Date.now()
  listId: string,
  dueDate?: string,     // 'YYYY-MM-DD' (ローカル時刻ベース)
  startDate?: string,   // 'YYYY-MM-DD' 開始日（未来日のみ表示）
  folderPath?: string,
  linkType?: string,    // 'folder' | 'url'
  detail?: string,
  parentId?: string,    // 値があればサブタスク（指す相手は必ずメイン＝parentIdなし）
  completedAt?: number, // チェックON時にDate.now()自動セット／OFFでundefined
  _trashedWithParent?: string, // 親と共にゴミ箱化されたサブの目印（永続化はされるがエクスポートから除外）
}
```

### サブタスクの制約

- **2階層固定**: `parentId` が指せるのは必ず「`parentId` を持たないメイン」のみ
- メインがサブ有りの場合、そのメインをさらに別メインの `parentId` 配下に入れることは禁止（ドラッグでも拒否）
- メモリスト（`list.type === 'memo'`）にはサブを置かない。リスト間移動でメモリストに入ったサブは自動的に `parentId` が解除される（[TList.html:1850-1851](../../TList.html)）

### 完了日時 `completedAt`

`toggleTodo()` で `t.completed` を反転した直後に以下を実行（[TList.html:1603-1604](../../TList.html)）:

```javascript
if (t.completed) t.completedAt = Date.now();
else t.completedAt = undefined;
```

サブタスク機能導入以前から完了になっていたタスクには `completedAt` が無いため、完了日時ラベルは表示されません（再度OFF→ONで付与）。

## リスト構造（`lists` の要素）

```javascript
{
  id: string,
  name: string,
  createdAt: number,
  type?: string,        // 'memo' のときメモリスト、未指定または 'todo' で通常リスト

```

## ゴミ箱構造

- `trash`: `todos` と同じ形（削除されたタスク）
- `listTrash`: `lists` の項目 + 関連 `todos`（リスト復元時に元のタスクも戻すため）

## 永続化（`load()` / `save()`）

`load()` は起動時に1回呼ばれ、`save()` は状態を変えるたびに呼ばれます。

```javascript
function load() {
  try { lists = JSON.parse(localStorage.getItem('todo-app-lists') || '[]'); } catch { lists = []; }
  if (!lists.length) {
    lists = [{ id: crypto.randomUUID(), name: 'マイタスク', createdAt: Date.now() }];
  }
  try { todos = JSON.parse(localStorage.getItem('todo-app-todos') || '[]'); } catch { todos = []; }
  try { trash = JSON.parse(localStorage.getItem('todo-app-trash') || '[]'); } catch { trash = []; }
  try { listTrash = JSON.parse(localStorage.getItem('todo-app-list-trash') || '[]'); } catch { listTrash = []; }

  // listId の欠損補完（古いデータ向け）
  const defId = lists[0].id;
  todos = todos.map(t => t.listId ? t : { ...t, listId: defId });
  trash = trash.map(t => t.listId ? t : { ...t, listId: defId });

  // 選択リストの復元
  const savedListId = localStorage.getItem('todo-app-selected-list');
  selectedListId = (savedListId && lists.find(l => l.id === savedListId))
    ? savedListId : lists[0].id;
}

function save() {
  localStorage.setItem('todo-app-todos',  JSON.stringify(todos));
  localStorage.setItem('todo-app-trash',  JSON.stringify(trash));
  localStorage.setItem('todo-app-lists',  JSON.stringify(lists));
  localStorage.setItem('todo-app-list-trash', JSON.stringify(listTrash));
  localStorage.setItem('todo-app-selected-list', selectedListId);
}
```

### 初回起動時のデフォルト

`lists` が空なら `'マイタスク'` リストを1件自動生成。

### マイグレーション

`load()` 内で `t.listId` が無い古いタスク／ゴミ箱項目を、先頭リストのIDに紐付け直します。スキーマバージョン管理は明示的にはしていません（エクスポートJSONの `version: 1` のみ）。

サブタスク機能で追加された `parentId` / `startDate` / `completedAt` は **任意プロパティ** として扱い、旧データに無くてもそのまま動作します（`undefined` = メインタスク扱い、`startDate` 未設定 = 開始日表示なし、`completedAt` 未設定 = 完了日時表示なし）。明示的なマイグレーションコードは不要。

### 折りたたみ状態 `collapsedIds`

サブを持つメインの折りたたみ状態は `Set<string>` でメモリに保持。**localStorage には保存しません**（リロード／再起動で全展開）。意図的な仕様で、フィルター切替や検索的な動作と独立して扱うため。

### 描画整列 `arrangeForRender(visibleList)`

`filtered()` の結果を渡すと、`currentTodos()` を元順で走査して「メイン → そのサブ群」を出力します（[TList.html:1055-1077](../../TList.html)）。`collapsedIds` に入ったメインのサブは出力から除外、親が現在リストに存在しない孤児サブは末尾に追加（保険ロジック）。

## 保存タイミング

| 操作 | 保存有無 |
|---|---|
| タスクCRUD | あり |
| リスト操作 | あり |
| `selectedListId` 変更 | あり |
| `filter` / UI状態（`sidebarOpen` 等） | なし（個別キーで保存するもの除く） |
| `showListStats` | 専用キー `todo-app-show-stats` |
| `addToTop` / `autoSort` | 専用キー（一覧は [05-1](../05_リファレンス/05-1_localStorageキー一覧.md)） |
| `darkMode` | 専用キー `darkMode` |
| `collapsedIds`（サブ折りたたみ） | なし（セッション内のみ保持） |
