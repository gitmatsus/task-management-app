## タスク構造（`todos` の要素）

```javascript
{
  id: string,             // crypto.randomUUID()
  text: string,           // タスク本文（改行含む可）
  completed: boolean,
  createdAt: number,      // Date.now()
  listId: string,
  dueDate?: string,       // 'YYYY-MM-DD' 終了日
  startDate?: string,     // 'YYYY-MM-DD' 開始日（メイン・サブ両方）
  completedAt?: number,   // 完了時刻（チェック時に自動付与）
  folderPath?: string,
  linkType?: string,      // 'folder' | 'url'
  detail?: string,
  parentId?: string,      // サブタスクの親メインID（2階層固定）
  recurrence?: {          // 繰り返し設定（あれば繰り返しタスク）
    type: 'daily' | 'weekly' | 'monthly',
    weekday?: 0-6,
    day?: 1-31 | 'last',
  },
  _trashedWithParent?: string, // ゴミ箱内部用（エクスポート時は除外）
}
```

### サブタスクの制約

- **2階層固定**: `parentId` が指せるのは必ず「`parentId` を持たないメイン」のみ
- サブを持つメインを別メインのサブにすることは禁止（ドラッグ時に拒否）
- メモリスト（`list.type === 'memo'`）でもサブを完全サポート（`9e54034`, `292f859`）

### 完了日時 `completedAt`

`toggleTodo()` で `t.completed` を反転した直後に以下を実行:

```javascript
if (t.completed) t.completedAt = Date.now();
else t.completedAt = undefined;
```

サブタスク機能導入以前から完了になっていたタスクには `completedAt` が無いため、完了日時ラベルは表示されません（再度OFF→ONで付与）。

### 繰り返し `recurrence`

詳細は [02-2 期限と表示制御](../02_機能ガイド/02-2_期限と表示制御.md) §「繰り返しタスク」と [HANDOFF.md](../../HANDOFF.md) §「繰り返しタスク仕様」を参照。

## リスト構造（`lists` の要素）

```javascript
{
  id: string,
  name: string,
  createdAt: number,
  type?: 'todo' | 'memo',  // memo はチェック概念なし
}
```

## ゴミ箱構造

- `trash`: `todos` と同じ形（削除されたタスク）
- `listTrash`: `lists` の項目 + 関連 `todos`（リスト復元時に元のタスクも戻すため）

## 永続化（`load()` / `save()`）

```javascript
function load() {
  try { lists = JSON.parse(localStorage.getItem('todo-app-lists') || '[]'); } catch { lists = []; }
  if (!lists.length) {
    lists = [{ id: crypto.randomUUID(), name: 'マイタスク', createdAt: Date.now() }];
  }
  try { todos = JSON.parse(localStorage.getItem('todo-app-todos') || '[]'); } catch { todos = []; }
  try { trash = JSON.parse(localStorage.getItem('todo-app-trash') || '[]'); } catch { trash = []; }
  try { listTrash = JSON.parse(localStorage.getItem('todo-app-list-trash') || '[]'); } catch { listTrash = []; }

  // listId の欠損補完（古いデータ向け）
  const defId = lists[0].id;
  todos = todos.map(t => t.listId ? t : { ...t, listId: defId });
  trash = trash.map(t => t.listId ? t : { ...t, listId: defId });

  // マイグレーション（後述）
  // 選択リストの復元
}

function save() {
  localStorage.setItem('todo-app-todos',  JSON.stringify(todos));
  localStorage.setItem('todo-app-trash',  JSON.stringify(trash));
  localStorage.setItem('todo-app-lists',  JSON.stringify(lists));
  localStorage.setItem('todo-app-list-trash', JSON.stringify(listTrash));
  localStorage.setItem('todo-app-selected-list', selectedListId);
}
```

### マイグレーション（`load()` 内）

旧データを読み込んだ時の自動修復:

1. **`listId` 欠損補完**: 先頭リストのIDに紐付け直し
2. **孤児サブの修復**: 親が存在しない／親が別リストにある／親自身がサブの場合は `parentId` をクリア
3. **`todos` の id 重複を除去**（過去の復元バグで重複した場合に最初の1件のみ残す）
4. **ゴミ箱に残った「親不在の paired サブ」を除去**（過去の `_trashedWithParent` バグの残骸）
5. **`recurrence` 型チェック**: `typeof t.recurrence !== 'object'` ならクリア

### サブタスク機能で追加された任意プロパティ

`parentId` / `startDate` / `completedAt` / `recurrence` はいずれも **任意プロパティ** として扱い、旧データに無くてもそのまま動作します。明示的なマイグレーションコードは上記の最小限のみ。

### 折りたたみ状態は永続化しない

- `collapsedIds`（サブ折りたたみ）
- `expandedDoneSubs`（完了サブヘッダー展開）
- `showCompletedSection`（完了セクション開閉）
- `taskFilter`（フィルターチップ）

これらは `Set<string>` ／グローバル変数でメモリ保持のみ。**localStorage には保存しません**（リロード／再起動で全リセット）。意図的な仕様で、フィルター切替や検索的な動作と独立に扱うため。

### 描画整列 `arrangeForRender(visibleList)`

`filtered()` の結果を渡すと、`currentTodos()` を元順で走査して「メイン → そのサブ群」を出力します。`collapsedIds` に入ったメインのサブは出力から除外。完了サブが残っているグループには `▷ 完了 (N件)` ヘッダー行を挟みます。

## 保存タイミング

| 操作 | 保存有無 | キー |
|---|---|---|
| タスクCRUD（追加/編集/削除/完了切替） | あり | `todo-app-todos` / `todo-app-trash` |
| リスト操作 | あり | `todo-app-lists` / `todo-app-list-trash` |
| `selectedListId` 変更 | あり | `todo-app-selected-list` |
| 繰り返し周期境界リセット | あり（`applyRecurringResets()` で `save()` 呼び出し） | `todo-app-todos` |
| `showListStats` | 専用キー | `todo-app-show-stats` |
| `darkMode` | 専用キー | `darkMode`（プレフィックスなしのレガシー名） |
| `collapsedIds` / `expandedDoneSubs` / `taskFilter` / `showCompletedSection` | なし（セッション内のみ保持） | — |

> 廃止された localStorage キー: `todo-app-add-to-top`, `todo-app-auto-sort`（残っていても読み込まれません）
