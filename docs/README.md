# タスク管理アプリ 開発者向けドキュメント

`TList.html`（単一HTMLファイル、約2600行、バニラJS + localStorage）を中心とした、ブラウザ・Electron・Tauri・Photinoで動作するタスク管理アプリの開発者資料です。

## 想定読者

- 本アプリのコードを読み書きする開発者（社内・JS経験有）
- ネイティブパッケージ（Electron/Tauri/Photino）のいずれかをビルド・調整する担当
- 既存資料（`HANDOFF.md`）を読んだうえで、章別に整理された情報を参照したい人
